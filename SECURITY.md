# Security Policy

BLACK ICE is an early-stage security project. It is not a certified security product, and its controls cover only actions routed through the documented API and registered adapters. See [`SECURITY_STATUS.md`](SECURITY_STATUS.md) for the current implementation boundary and known limitations.

## Reporting a vulnerability

Please do not publish exploit details, credentials, private data, or a working attack against a real system in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If it is not enabled, contact the repository owner privately through GitHub and include a concise description, affected version/commit, reproduction steps using synthetic data where possible, and the potential impact.

Do not test against third-party systems, other users' deployments, or production services without explicit authorization. Avoid attaching live secrets or personal data. We will acknowledge and assess reports as maintainer availability permits; no response or remediation deadline is guaranteed.

## Supported versions

Until a stable release policy exists, security fixes are considered only for the current repository state on `main`. No release or support commitment is implied.
